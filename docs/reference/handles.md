# Handles (`reportnet_api.handles`)

> Generated by `scripts/generate_docs.py` (`scripts/regen_docs.sh`). Do not edit by hand.

Handles are frozen dataclasses from `reportnet_api.handles` that delegate to the `easy` functions and add no endpoint, so the ReportNet rights needed are those of those calls. Get one with `easy.find_dataflow(client, id_or_name)` (`flow`), then `flow.dataset(id, country code or name)` (`ds`). A handle is a snapshot: `flow.refresh()` returns a new one.Properties are written without brackets.

### Dataflow.dataset

**Returns:** `Dataset`

A string is tried as a provider code (case-insensitive), then as a name:
exact first, then substring. `kind` ("design", "reporting", "test", ...)
narrows the candidates first.

| `**kwargs` | `Any` | no |  |  |

**Returns:** `dict[str, pd.DataFrame]`

The handle's `provider_id` is passed unless you give one. Other keyword
arguments (`page_size`, `progress`, `table_schema_id`) go to `read_tables`;

`allow_data_lake=True` to try anyway.
